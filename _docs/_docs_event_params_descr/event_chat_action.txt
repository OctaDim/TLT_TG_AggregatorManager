ПОЛНЫЙ СПИСОК ПАРАМЕТРОВ ДЛЯ events.ChatAction.Event В TELEGRAM/TELETHON

================================================================================
ОСНОВНЫЕ ПАРАМЕТРЫ СОБЫТИЯ ChatAction.Event
================================================================================

ChatAction.Event генерируется при различных действиях в чатах: вход/выход пользователей,
создание чатов, изменение названия, фото и других событий.

1. original_update - UpdateChatParticipantAdd/UpdateChatParticipantDelete/UpdateChannelParticipant и др. - Исходный объект обновления
2. pattern_match - Match или None - Результаты сопоставления с регулярным выражением
3. _client - TelegramClient - Ссылка на клиент Telethon (внутреннее использование)
4. _chat - Chat/Channel/User или None - Кешированный объект чата/диалога
5. _entities - Dict[int, Union[User, Chat, Channel]] или None - Словарь кешированных сущностей
6. _user - User или None - Кешированный объект пользователя, совершившего действие
7. _user_id - int или None - ID пользователя, совершившего действие
8. _action - MessageAction - Объект действия из сообщения (если применимо)
9. _message - Message или None - Сообщение с информацией о действии
10. _inviter - User или None - Пользователь, который пригласил (для добавлений)
11. _added_by - User или None - Альтернативное название для inviter
12. _kicked - bool - Флаг, был ли пользователь исключен
13. _created - bool - Флаг создания чата
14. _new_title - str или None - Новое название чата
15. _new_photo - ChatPhoto или None - Новое фото чата
16. _deleted_photo - bool - Флаг удаления фото
17. _pinned_message - Message или None - Закрепленное сообщение
18. _migrated_to - InputChannel или None - Канал, в который мигрировал чат
19. _migrated_from - int или None - ID чата, из которого мигрировали

================================================================================
ТИПЫ original_update ДЛЯ ChatAction.Event
================================================================================

1. UpdateChatParticipantAdd - Добавление участника в чат
2. UpdateChatParticipantDelete - Удаление участника из чата
3. UpdateChannelParticipant - Изменение участника в канале/супергруппе
4. UpdateChatDefaultBannedRights - Изменение прав по умолчанию в чате
5. UpdateChatParticipants - Изменение списка участников чата
6. UpdateChatUserTyping - Пользователь печатает в чате
7. UpdateChat - Изменение информации о чате
8. UpdateChannel - Изменение информации о канале
9. UpdateNewMessage - Новое сообщение с действием (MessageAction)
10. UpdateEditMessage - Редактирование сообщения с действием

ПРИМЕРЫ ДОСТУПА К ПАРАМЕТРАМ:
================================================================================

# ID пользователя, совершившего действие
user_id = event.user_id

# Объект пользователя
user = await event.get_user()

# Объект чата
chat = await event.get_chat()

# Тип действия
if event.user_joined:
    print(f"Пользователь {user_id} присоединился")
elif event.user_left:
    print(f"Пользователь {user_id} вышел")
elif event.user_kicked:
    print(f"Пользователь {user_id} был исключен")
elif event.user_added:
    print(f"Пользователь {user_id} был добавлен")

# Для добавлений: кто пригласил
if event.inviter:
    print(f"Пригласил: {event.inviter.first_name}")

# Изменение названия
if event.chat_title_changed:
    print(f"Название изменено на: {event.new_title}")
    old_title = await event.get_old_title()

# Изменение фото
if event.chat_photo_changed:
    print("Фото чата изменено")
    new_photo = event.new_photo
    old_photo = await event.get_old_photo()

# Закрепление сообщения
if event.new_pin:
    pinned_msg = await event.get_pinned_message()
    print(f"Закреплено сообщение: {pinned_msg.text}")

# Миграция чата
if event.chat_migrated:
    print(f"Чат мигрировал в канал {event.migrated_to.channel_id}")

# Статус печатания
if event.typing:
    print(f"Пользователь {user_id} печатает...")
elif event.recording_audio:
    print(f"Пользователь {user_id} записывает аудио...")
elif event.uploading_photo:
    print(f"Пользователь {user_id} загружает фото...")

# Для каналов: изменение прав администратора
if event.user_admin:
    print(f"Пользователю {user_id} выданы права администратора")

# Проверка типа чата
if event.is_group:
    print("Действие в группе")
elif event.is_channel:
    print("Действие в канале")
    if event.is_supergroup:
        print("Это супергруппа")
    elif event.is_broadcast:
        print("Это широковещательный канал")

# Получить сообщение с действием
action_msg = await event.get_action_message()
if action_msg:
    print(f"Сообщение действия: {action_msg.text}")

# Для UpdateChannelParticipant
if hasattr(event.original_update, 'prev_participant'):
    prev = event.original_update.prev_participant
    new = event.original_update.new_participant
    print(f"Статус: {type(prev).__name__} -> {type(new).__name__}")

           stats['action_type'] = 'kick'
