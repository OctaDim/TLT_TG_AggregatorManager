ВНИМАНИЕ:
1. Многие параметры могут быть None, если они не применимы к конкретному сообщению
2. Типы медиа и клавиатур различаются в зависимости от содержимого сообщения
3. Некоторые параметры доступны только в определенных типах чатов (каналы, супергруппы)
4. Для безопасного доступа к вложенным параметрам используйте проверки (пример
   получения значения одного параметра reply_to):
   if event.message.reply_to:
       if event.message:
           if event.message.reply_to:
               msg_id = event.message.reply_to.reply_to_msg_id
================================================================================

5. Свойства (properties) являются вычисляемыми и не хранятся напрямую в объекте
