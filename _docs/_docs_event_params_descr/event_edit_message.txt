ПОЛНЫЙ СПИСОК ПАРАМЕТРОВ ДЛЯ events.MessageEdited.Event В TELEGRAM

================================================================================
ОСНОВНЫЕ ПАРАМЕТРЫ СОБЫТИЯ MessageEdited.Event
================================================================================

MessageEdited.Event генерируется, когда сообщение редактируется.

1. original_update - UpdateEditMessage/UpdateEditChannelMessage - Исходный объект обновления от Telegram API
2. pattern_match - Match или None - Результаты сопоставления с регулярным выражением из фильтра
3. message - Message - Объект отредактированного сообщения с новыми данными
4. _client - TelegramClient - Ссылка на клиент Telethon (внутреннее использование)
5. _chat - Chat/Channel/User или None - Кешированный объект чата/диалога
6. _entities - Dict[int, Union[User, Chat, Channel]] или None - Словарь кешированных сущностей
7. _reply_message - Message или None - Кешированное сообщение-ответ
8. _sender - User или Channel - Кешированный объект отправителя
9. _input_sender - InputPeer - Входной объект отправителя для API-вызовов
10. _message_id - int - ID отредактированного сообщения
11. _chat_peer - Peer - Peer объекта чата
12. _sender_id - int - ID отправителя
13. _broadcast - bool - Флаг, является ли чат каналом/супергруппой
14. _old_message - Message или None - Предыдущая версия сообщения (до редактирования)
15. _edited - bool - Флаг редактирования (всегда True)

================================================================================
ТИПЫ original_update ДЛЯ MessageEdited.Event
================================================================================

1. UpdateEditMessage - Редактирование сообщения в личном чате/группе
2. UpdateEditChannelMessage - Редактирование сообщения в канале/супергруппе

================================================================================
ПАРАМЕТРЫ UpdateEditMessage
================================================================================

Используется, когда сообщение в личном чате или группе редактируется.

• message - Message - Объект отредактированного сообщения
• pts - int - PTS (sequence для обновлений)
• pts_count - int - Количество PTS

================================================================================
ПАРАМЕТРЫ UpdateEditChannelMessage
================================================================================

Используется, когда сообщение в канале/супергруппе редактируется.

• message - Message - Объект отредактированного сообщения
• pts - int - PTS (sequence для обновлений)
• pts_count - int - Количество PTS

================================================================================
ОБЪЕКТ MESSAGE В СОБЫТИИ MessageEdited.Event
================================================================================

Содержит те же 48 параметров, что и в NewMessage, но с акцентом на следующие изменения:

1. id - int - ID сообщения (остается прежним)
2. edit_date - datetime - Новая дата и время редактирования (обновляется)
3. message - str - Новый текст сообщения (измененный)
4. entities - List[MessageEntity] или None - Новые сущности форматирования
5. media - Разные типы медиа или None - Медиа может быть изменено/удалено
6. edit_hide - bool - Скрывать ли отметку об редактировании
7. reply_markup - Разные типы клавиатур или None - Клавиатура может быть изменена
8. views - int или None - Для каналов: счетчик просмотров может измениться
9. forwards - int или None - Количество пересылок может измениться
10. reactions - MessageReactions или None - Реакции могут быть изменены

МЕТОДЫ СОБЫТИЯ MessageEdited.Event
================================================================================

1. get_old_message() -> Message или None - Получить предыдущую версию сообщения
2. get_chat() -> Chat/Channel/User - Получить объект чата
3. get_sender() -> User/Channel - Получить объект отправителя
4. get_input_chat() -> InputPeer - Получить InputPeer объекта чата
5. get_reply_message() -> Message или None - Получить сообщение-ответ
6. get_diff() -> Dict[str, Any] - Получить различия между старой и новой версиями
7. download_media() -> bytes или str - Скачать медиа из сообщения
8. reply() - Ответить на сообщение
9. respond() - Ответить на сообщение (альтернативный метод)
10. forward_to() - Переслать сообщение
11. edit() - Отредактировать сообщение (создать новое редактирование)
12. delete() - Удалить сообщение
13. pin() - Закрепить сообщение
14. unpin() - Открепить сообщение
15. get_replies() - Получить ответы на сообщение
16. react() - Добавить реакцию
17. mark_read() - Пометить как прочитанное

----------------------------------------------------------------
• results: List[ReactionCount] - Список реакций и их счетчиков

• can_see_list: bool - Можно ли просмотреть список реакций
• reactions_as_tags: bool - Реакции как теги
• recent_reactions: List[MessagePeerReaction] - Последние реакции

5. ПАРАМЕТРЫ replies (ТИП MessageReplies):
----------------------------------------------------------------
• replies: int - Количество ответов
• replies_pts: int - PTS для ответов
• comments: bool - Флаг комментариев
• recent_repliers: List[Peer] - Последние ответившие
• channel_id: int или None - ID канала для комментариев
• max_id: int или None - Максимальный ID ответа
• read_max_id: int или None - Максимальный прочитанный ID

ПРИМЕРЫ ДОСТУПА К ПАРАМЕТРАМ:

# Новый текст сообщения
new_text = event.text

# Старый текст (если доступен)
old_text = event.old_text

# ID сообщения
message_id = event.message_id

# ID чата
chat_id = event.chat_id

# ID отправителя
sender_id = event.sender_id

# Дата редактирования
edit_time = event.edit_date

# Скрыта ли отметка об редактировании
if event.hide_edit:
    print("Редактирование скрыто")

# Проверка типа чата
if event.is_private:
    print("Личный чат")
elif event.is_group:
    print("Группа")
elif event.is_channel:
    print("Канал")

# Получить предыдущую версию сообщения
old_message = await event.get_old_message()
if old_message:
    print(f"Было: {old_message.text}")
    print(f"Стало: {event.text}")

# Проверить, что изменилось
if event.changed_text:
    print("Текст изменился")

if event.changed_media:
    print("Медиа изменилось")

# Получить различия
diff = await event.get_diff()
if 'text' in diff:
    print(f"Текст изменен: {diff['text']['old']} -> {diff['text']['new']}")

# Для каналов: количество просмотров
if event.message.views:
    print(f"Просмотры: {event.message.views}")

# Реакции на сообщение
if event.message.reactions:
    for reaction in event.message.reactions.results:
        print(f"{reaction.reaction}: {reaction.count}")

# Сущности форматирования
if event.message.entities:
    for entity in event.message.entities:
        print(f"Сущность: {type(entity).__name__}")

================================================================================
ОСОБЫЕ СЛУЧАИ ДЛЯ MessageEdited.Event:
================================================================================

1. Редактирование с изменением медиа:
   - Фото может быть заменено
   - Документ может быть заменен
   - Геолокация может быть обновлена
   - Опрос может быть изменен (до определенного времени)

2. Редактирование в каналах:
   - Только администраторы могут редактировать сообщения
   - В каналах edit_hide часто равно True
   - views может увеличиваться между редактированиями

3. Редактирование с изменением клавиатуры:
   - Inline-клавиатура может быть полностью заменена
   - Callback данные могут быть изменены

4. Массовое редактирование:
   - Боты могут редактировать множество сообщений
   - PTS может увеличиваться на несколько единиц

5. Редактирование старых сообщений:
   - В личных чатах можно редактировать без ограничений
   - В группах и каналах могут быть ограничения по времени

================================================================================
ОГРАНИЧЕНИЯ И ОСОБЕННОСТИ:
================================================================================

1. Время редактирования:
   - Личные чаты: без ограничений
   - Группы: обычно 48 часов для обычных пользователей
   - Каналы: без ограничений для администраторов

2. Ограничения медиа:
   - Нельзя заменить медиа на медиа другого типа (фото на документ)
   - Можно удалить медиа (заменить на текст)
   - Размер медиа ограничен

3. Ограничения форматирования:
   - Сущности должны быть валидными
   - Длина текста ограничена (4096 символов)
   - Некоторые сущности доступны только в определенных чатах

4. Частота редактирования:
   - Flood-контроль Telegram
   - Ограничения по времени между редактированиями
   - Ограничения для новых пользователей

    },
    'reply_markup': {
        'old': old_markup,
        'new': new_markup,
        'changed': True/False
    },
    'edit_date': {
        'old': old_edit_date,
        'new': new_edit_date
    }
}

ОБРАБОТКА ОШИБОК:

3. Ограничение частоты:
