ПОЛНЫЙ СПИСОК ПАРАМЕТРОВ ДЛЯ events.MessageRead.Event В TELEGRAM/TELETHON

================================================================================
ОСНОВНЫЕ ПАРАМЕТРЫ СОБЫТИЯ MessageRead.Event
================================================================================

MessageRead.Event генерируется, когда сообщения помечаются как прочитанные.

1. original_update - UpdateReadHistoryInbox/UpdateReadHistoryOutbox/UpdateReadChannelInbox/UpdateReadChannelOutbox - Исходный объект обновления от Telegram API
2. pattern_match - Match или None - Результаты сопоставления с регулярным выражением из фильтра (обычно None для этого события)
3. _client - TelegramClient - Ссылка на клиент Telethon (внутреннее использование)
4. _chat - Chat/Channel/User или None - Кешированный объект чата/диалога
5. _entities - Dict[int, Union[User, Chat, Channel]] или None - Словарь кешированных сущностей
6. _message_ids - List[int] или None - Кешированные ID сообщений
7. _outbox - bool - Флаг исходящих сообщений (прочитаны ваши сообщения)
8. _max_id - int - Максимальный ID прочитанного сообщения
9. _peer - Peer или None - Peer чата/диалога
10. _channel_id - int или None - ID канала (если применимо)

================================================================================
ТИПЫ original_update ДЛЯ MessageRead.Event
================================================================================

1. UpdateReadHistoryInbox - Прочитаны входящие сообщения в личном чате/группе
2. UpdateReadHistoryOutbox - Прочитаны исходящие сообщения в личном чате/группе
3. UpdateReadChannelInbox - Прочитаны входящие сообщения в канале
4. UpdateReadChannelOutbox - Прочитаны исходящие сообщения в канале

================================================================================
ПАРАМЕТРЫ UpdateReadHistoryInbox
================================================================================

Используется, когда входящие сообщения в личном чате или группе помечаются как прочитанные.

• peer - Peer - Объект чата, в котором прочитаны сообщения
• max_id - int - Максимальный ID прочитанного сообщения
• still_unread_count - int - Количество непрочитанных сообщений (для игнорирования)
• pts - int - PTS (sequence для обновлений)
• pts_count - int - Количество PTS

Поля peer:
  - PeerUser: user_id: int - ID пользователя (личный чат)
  - PeerChat: chat_id: int - ID чата (группа)
  - PeerChannel: channel_id: int - ID канала (но для каналов обычно используется UpdateReadChannelInbox)

================================================================================
ПАРАМЕТРЫ UpdateReadHistoryOutbox
================================================================================

Используется, когда исходящие сообщения (отправленные вами) помечаются как прочитанные другим пользователем.

• peer - Peer - Объект чата, в котором прочитаны сообщения
• max_id - int - Максимальный ID прочитанного сообщения
• pts - int - PTS (sequence для обновлений)
• pts_count - int - Количество PTS

================================================================================
ПАРАМЕТРЫ UpdateReadChannelInbox
================================================================================

Используется, когда входящие сообщения в канале/супергруппе помечаются как прочитанные.

• channel_id - int - ID канала
• max_id - int - Максимальный ID прочитанного сообщения
• still_unread_count - int - Количество непрочитанных сообщений (для игнорирования)
• pts - int - PTS (sequence для обновлений)
• pts_count - int - Количество PTS

================================================================================
ПАРАМЕТРЫ UpdateReadChannelOutbox
================================================================================

Используется, когда исходящие сообщения в канале/супергруппе (отправленные вами) помечаются как прочитанные.

• channel_id - int - ID канала
• max_id - int - Максимальный ID прочитанного сообщения
• pts - int - PTS (sequence для обновлений)
• pts_count - int - Количество PTS

================================================================================
СВОЙСТВА (PROPERTIES) СОБЫТИЯ MessageRead.Event
================================================================================

1. message_ids - List[int] - Список ID сообщений, которые были прочитаны (все сообщения с ID ≤ max_id)
2. max_id - int - Максимальный ID прочитанного сообщения
3. peer - Peer - Объект чата/диалога
4. chat_id - int - ID чата (извлеченный из peer)
5. channel_id - int или None - ID канала (если применимо)
6. outbox - bool - Флаг исходящих сообщений (True если прочитаны ваши сообщения другим пользователем)
7. inbox - bool - Флаг входящих сообщений (True если вы прочитали сообщения от других)
8. is_private - bool - Является ли личным чатом
9. is_group - bool - Является ли групповым чатом
10. is_channel - bool - Является ли каналом/супергруппой
11. chat - Chat/Channel/User или None - Объект чата (если доступен в кеше)
12. sender - User или None - Отправитель (для личных чатов)
13. broadcast - bool - Является ли каналом с широковещательными сообщениями

================================================================================
МЕТОДЫ СОБЫТИЯ MessageRead.Event
================================================================================

1. get_messages() -> List[Message] или Message - Получить объекты прочитанных сообщений
2. get_input_chat() -> InputPeer - Получить InputPeer объекта чата
3. get_chat() -> Chat/Channel/User - Получить объект чата (загружает при необходимости)
4. get_sender() -> User - Получить объект отправителя (для личных чатов)

================================================================================
ВЛОЖЕННЫЕ СТРУКТУРЫ И ИХ ПОЛЯ
================================================================================

1. ПАРАМЕТРЫ peer (ТИП Peer И НАСЛЕДНИКИ):
----------------------------------------------------------------
- PeerUser:
  • user_id: int - ID пользователя (личный чат)

- PeerChat:
  • chat_id: int - ID обычного чата (группа)

- PeerChannel:
  • channel_id: int - ID канала/супергруппы

2. ПАРАМЕТРЫ chat (ЕСЛИ ДОСТУПЕН В КЕШЕ):
----------------------------------------------------------------
-- User (для личных чатов):
  • id: int - ID пользователя
  • access_hash: int - Хэш доступа
  • first_name: str - Имя
  • last_name: str или None - Фамилия
  • username: str или None - Юзернейм
  • phone: str или None - Номер телефона
  • photo: UserProfilePhoto или None - Фото профиля
  • status: UserStatus - Статус пользователя
  • bot: bool - Является ли ботом
  • verified: bool - Верифицирован ли
  • restricted: bool - Ограничен ли
  • scam: bool - Помечен как мошенник
  • fake: bool - Помечен как фейк
  • bot_chat_history: bool - Доступна ли история бота
  • bot_nochats: bool - Может ли бот добавляться в чаты
  • premium: bool - Имеет ли Telegram Premium

-- Chat (для групп):
  • id: int - ID чата
  • title: str - Название чата
  • photo: ChatPhoto или None - Фото чата
  • participants_count: int - Количество участников
  • date: datetime - Дата создания
  • version: int - Версия чата
  • creator: bool - Являетесь ли вы создателем
  • left: bool - Покинули ли вы чат
  • deactivated: bool - Деактивирован ли чат
  • call_active: bool - Активен ли звонок
  • call_not_empty: bool - Есть ли участники в звонке
  • noforwards: bool - Запрещена пересылка
  • migrated_to: InputChannel или None - Мигрировал в канал

-- Channel (для каналов/супергрупп):
  • id: int - ID канала
  • access_hash: int - Хэш доступа
  • title: str - Название канала
  • username: str или None - Юзернейм
  • photo: ChatPhoto или None - Фото канала
  • date: datetime - Дата создания
  • version: int - Версия канала
  • broadcast: bool - Широковещательный канал (канал) или супергруппа
  • megagroup: bool - Супергруппа
  • restricted: bool - Ограничен ли
  • signatures: bool - Показывать подписи
  • min: bool - Минимальная информация
  • scam: bool - Помечен как мошенник
  • fake: bool - Помечен как фейк
  • gigagroup: bool - Гигагруппа
  • noforwards: bool - Запрещена пересылка
  • join_to_send: bool - Нужно вступать для отправки сообщений
  • join_request: bool - Нужно одобрение для вступления
  • participants_count: int или None - Количество участников

================================================================================
СВОЙСТВА ПРОЧИТАННЫХ СООБЩЕНИЙ
================================================================================

При использовании метода get_messages() возвращаются объекты Message со следующими полями,
которые могут быть изменены при прочтении:

1. out - bool - Для исходящих сообщений: изменяется на True с отметкой прочтения
2. media_unread - bool - Для сообщений с медиа: изменяется на False
3. mentioned - bool - Для сообщений с упоминаниями: может изменяться
4. reactions - MessageReactions - Реакции могут обновляться
5. views - int - Для каналов: счетчик просмотров может увеличиваться

event.max_id

event.message_ids

# Peer объекта чата
event.peer

event.chat_id

if isinstance(event.peer, PeerUser):

if isinstance(event.peer, PeerChannel):

# Флаг исходящих сообщений (прочитаны ли ваши сообщения)
if event.outbox:

# Флаг входящих сообщений (вы прочитали чужие сообщения)
if event.inbox:

# Получить объекты прочитанных сообщений
messages = await event.get_messages()

# Получить объект чата

# Проверить тип чата
if event.is_private:

elif event.is_group:
    print("Групповой чат")
elif event.is_channel:
    print("Канал/супергруппа")

# PTS и pts_count
pts = event.original_update.pts
pts_count = event.original_update.pts_count

# Количество непрочитанных сообщений (для игнорирования)

ПРАКТИЧЕСКИЕ СЦЕНАРИИ ИСПОЛЬЗОВАНИЯ:
================================================================================

1. Отслеживание прочтения ваших сообщений:
   @client.on(events.MessageRead(outbox=True))
   async def handler(event):
       print(f"Пользователь прочитал ваши сообщения до ID {event.max_id} в чате {event.chat_id}")

2. Отслеживание вашего прочтения сообщений:
   @client.on(events.MessageRead(inbox=True))
   async def handler(event):
       print(f"Вы прочитали сообщения до ID {event.max_id} в чате {event.chat_id}")

3. Только для личных чатов:
   @client.on(events.MessageRead(is_private=True))
   async def handler(event):
       print(f"Прочитаны сообщения в личном чате с пользователем {event.chat_id}")

4. Только для каналов:
   @client.on(events.MessageRead(is_channel=True))
   async def handler(event):
       print(f"Прочитаны сообщения в канале {event.channel_id} до ID {event.max_id}")

5. Получение прочитанных сообщений:
   @client.on(events.MessageRead())
   async def handler(event):
       messages = await event.get_messages()
       for msg in messages:
           print(f"Прочитано сообщение: {msg.text}")

================================================================================
ВАЖНЫЕ ЗАМЕЧАНИЯ:
================================================================================

1. Событие MessageRead может срабатывать массово - при прочтении всех сообщений до определенного ID
2. max_id означает, что все сообщения с ID ≤ max_id считаются прочитанными
3. Для каналов отдельно существуют события входящих и исходящих сообщений
4. Событие может приходить с задержкой из-за синхронизации между устройствами
5. PTS (Permanent Timestamp Sequence) используется для отслеживания порядка обновлений
6. still_unread_count обычно используется для игнорирования и может быть > 0
7. Событие может не содержать полной информации о чате, если он не был загружен ранее
8. Для получения объектов сообщений требуется дополнительный запрос к API
9. В супергруппах (megagroup) используется UpdateReadChannelInbox/Outbox, а не UpdateReadHistory
10. Для каналов, где вы не являетесь участником, события прочтения могут не приходить

# Проверка типа original_update
if isinstance(event.original_update, UpdateReadHistoryInbox):
    print("Прочитаны входящие в личном чате/группе")
elif isinstance(event.original_update, UpdateReadHistoryOutbox):
    print("Прочитаны исходящие в личном чате/группе")
elif isinstance(event.original_update, UpdateReadChannelInbox):
    print("Прочитаны входящие в канале")
elif isinstance(event.original_update, UpdateReadChannelOutbox):
    print("Прочитаны исходящие в канале")

# Получение InputPeer для API вызовов
input_chat = await event.get_input_chat()

# Проверка, является ли канал широковещательным
if event.broadcast:
    print("Это широковещательный канал")

# Получение отправителя (для личных чатов)
if event.is_private:
    sender = await event.get_sender()
    print(f"Отправитель: {sender.first_name}")

================================================================================
ИСКЛЮЧЕНИЯ И ОШИБКИ:
================================================================================

1. ChatNotFound - Если чат не найден (удален или недоступен)
2. ChannelInvalidError - Если канал недействителен
3. ChannelPrivateError - Если канал приватный и у вас нет доступа
4. UserNotParticipantError - Если вы не участник чата/канала
5. TimeoutError - При таймауте запроса к API

================================================================================
ОПТИМИЗАЦИЯ:
================================================================================

1. Кешируйте объекты чатов, чтобы избежать повторных запросов
2. Используйте фильтры для конкретных типов чатов
3. Обрабатывайте массовые прочтения пакетно, а не по одному сообщению
4. Используйте фоновые задачи для получения объектов сообщений
5. Учитывайте, что события могут дублироваться при многократном прочтении

Пример 1: Отметка прочтения в базе данных
@client.on(events.MessageRead())
async def mark_as_read_in_db(event):
    for msg_id in event.message_ids:
        # Обновить статус в базе данных
        await mark_message_read(event.chat_id, msg_id)

Пример 2: Уведомление о прочтении
@client.on(events.MessageRead(outbox=True, is_private=True))
async def notify_message_read(event):
    user = await event.get_sender()
    print(f"✅ {user.first_name} прочитал(а) ваши сообщения")

Пример 3: Аналитика прочтений в каналах
@client.on(events.MessageRead(is_channel=True, inbox=True))
async def channel_read_analytics(event):
    channel = await event.get_chat()
    print(f"📊 Прочитаны сообщения в канале '{channel.title}' до ID {event.max_id}")
